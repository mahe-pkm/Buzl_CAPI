    Google Apps Script Code for Google Sheets

    Follow these quick steps in Google Sheets to activate the CRM & Multi-Tab Engine:

    1. Open your target Google Sheet > Extensions > Apps Script.
    2. Paste the code below & click Save (Ctrl+S).
    3. Click the blue Deploy button (top right) > New deployment (or Manage deployments > New version if updating).
    4. Select type: Web app.
    5. Set Execute as: Me (your Google email).
    6. Set Who has access: Anyone (Critical: required for website leads).
    7. Click Deploy, authorize access, copy the /exec URL, and paste it into the field above!
    8. Refresh your Google Sheet and click ⚡ Buzl Lead CRM > ⚡ Initialize & Upgrade All CRM Tabs to automatically create all 6 status tabs with real-time dynamic filters!
