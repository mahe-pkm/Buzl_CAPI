1. Command Reference Matrix

All CLI commands and flags supported by npx @mahe_pkm/buzl-capi and npx buzl-tracker:

Command / Flag Short Argument Purpose
npx @mahe_pkm/buzl-capi — [dir] Launches interactive ANSI terminal setup wizard.
--gui -g [dir] Launches zero-dependency Web GUI dashboard on port 3333.
--backup [name] -b [dir] Creates a point-in-time SHA-1 snapshot backup.
--list-backups — [dir] Lists all saved snapshots stored in .buzl/snapshots/.
--restore [name] -r [dir] Restores HTML files to a named snapshot or latest.
--uninstall -u [dir] Cleanly strips all GTM, Meta Pixel, and runtime code.
--handbook — — Opens this User Handbook in your default browser.
--help -h — Displays the command-line help manual.

2. NPM Package Installation, Updates & Publishing

How to run, install, update, and publish @mahe_pkm/buzl-capi across Windows, macOS, and Linux:

2.1 Always Run Latest via NPX (Bypasses NPX Cache)

🪟 Windows / 🍎 macOS / 🐧 Linux 
# Force npx to fetch and run latest version
npx @mahe_pkm/buzl-capi@latest --gui

2.2 Global CLI Installation & Updating

🪟 Windows / 🍎 macOS / 🐧 Linux 
# Install or upgrade globally to latest
npm install -g @mahe_pkm/buzl-capi@latest

# Alternative: update existing global package
npm update -g @mahe_pkm/buzl-capi

2.3 Update as Local Project Dependency

🪟 Windows / 🍎 macOS / 🐧 Linux 
# Update package in project dependencies
npm install @mahe_pkm/buzl-capi@latest

2.4 Author Publishing Workflow (with 2FA / OTP)

🪟 Windows / 🍎 macOS / 🐧 Linux 
# 1. Bump version (patch / minor / major)
npm version patch

# 2. Push tags and commits to GitHub
git push origin main --tags

# 3. Publish with 2FA authenticator OTP code & explicit latest tag
npm publish --tag latest --otp=YOUR_6_DIGIT_OTP

🪟 Windows (PowerShell)

🍎 macOS / 🐧 Linux 
# Create named snapshot

List Saved Backups

🪟 Windows / 🍎 macOS / 🐧 Linux

Restore / Rollback to Snapshot

🪟 Windows / 🍎 macOS / 🐧 Linux

7. Daemon & Background Service Execution

Run the Web GUI daemon as a persistent background service:

🪟 Windows (PowerShell Background Job)

PowerShell 
# Launch GUI in background
Start-Process -FilePath "npx" -ArgumentList "@mahe_pkm/buzl-capi --gui" -WindowStyle Hidden

# Stop background GUI
Stop-Process -Id (Get-NetTCPConnection -LocalPort 3333).OwningProcess -Force

🍎 macOS / 🐧 Linux (nohup Background Daemon)

Terminal (zsh / bash) 
# Start daemon with log file
nohup npx @mahe_pkm/buzl-capi --gui > buzl-gui.log 2>&1 &

# Stop background GUI
kill $(lsof -t -i:3333)

8. Troubleshooting & Port Conflicts

Resolve port 3333 conflicts across platforms:

🪟 Windows (PowerShell) 
# Find and kill process on port 3333
Get-NetTCPConnection -LocalPort 3333 | Select-Object OwningProcess
Stop-Process -Id <PID> -Force
🍎 macOS / 🐧 Linux 
# Find and kill process on port 3333
sudo lsof -i :3333
sudo kill -9 $(lsof -t -i:3333)
